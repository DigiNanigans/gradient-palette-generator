# Grad Generator

A lightweight Preact application scaffolded with Vite, TypeScript, and Stylable.

## Development

```sh
pnpm install
pnpm dev
```

The app is served by Vite. Stylable definition files are generated into `st-types/`
and refreshed while the development server is running.

## Checks

```sh
pnpm typecheck
pnpm build
pnpm preview
```

Application code lives in `src/`, shared design tokens are in
`src/project.st.css`, and routes live in `src/routes/`.
